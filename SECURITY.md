# Security policy

## Supported versions

Security fixes are provided for the latest stable or preview release of version 2.

## Reporting a vulnerability

Please use GitHub's private security advisory feature for this repository. Do not open a public issue for a suspected vulnerability. Include affected versions, reproduction steps, impact, and any suggested mitigation.

## Logging sensitive data

Request bodies, response bodies, query strings, client IP addresses, and user agents are disabled by default. Enabling them is an application-level security and privacy decision. Redact secrets, restrict log access, set a retention period, and do not log credentials, authorization tokens, session cookies, payment data, or unnecessary personal data.
